# App Store 개인정보 보고서 항목표

App Store Connect의 "App Privacy" 입력값이다. 처리방침(`privacy/index.html`)과 설계 14장이 기준이며, 셋이 어긋나지 않게 함께 고친다.

**추적(Tracking):** 하지 않는다. 광고·분석 SDK가 없고 다른 회사 데이터와 결합하지 않는다.

| 데이터 유형(App Store 분류) | 수집 | 사용자와 연결 | 용도 | 근거 |
| --- | --- | --- | --- | --- |
| 연락처 정보 → 이메일 주소 | 예 | 예 | 앱 기능 | 소셜 로그인 제공자가 준 이메일, 계정 연동(설계 10.2) |
| 연락처 정보 → 이름 | 예 | 예 | 앱 기능 | 닉네임 |
| 식별자 → 사용자 ID | 예 | 예 | 앱 기능 | 인증 계정 id |
| 위치 → 대략적인 위치 | 예 | 예 | 앱 기능 | 사귄 날 이후 이용자가 비교를 승인한 날짜·시·군·구와 장수(설계 5.2). 정확한 위치는 수집하지 않음 |
| 사용자 콘텐츠 → 사진 또는 비디오 | 예 | 예 | 앱 기능 | 이용자가 고른 사진의 축소본, 위치·기기 정보 제거(설계 8.1.1) |
| 사용자 콘텐츠 → 기타 사용자 콘텐츠 | 예 | 예 | 앱 기능 | 여행 제목·기간, 사귄 날, 신고 접수, 방명록·사진 댓글(2026-11-19 출시 전으로 앞당김) |
| 위치 → 정확한 위치 | 아니요 | | | 기기 안에서만 사용 |
| 진단 → 충돌 데이터 | 예 | 아니요 | 앱 기능 | DSN을 설정한 출시 버전의 Flutter·Dart 오류 종류, 호출 스택, 앱·OS 버전, 기기 모델, 계정과 분리된 진단 ID |
| 사용 데이터·구매·금융 | 아니요 | | | 정산(2차)이 들어오면 금액을 다시 검토 |

2차에서 정산이 들어오면 "기타 금융 정보"(지출 금액)를, 푸시가 들어오면 기기 토큰을 추가로 검토한다.

비교 승인 기록은 서버에서 계정 본인에게만 직접 조회되며, 미승인 스캔은 OS 백업에서 제외되는 기기 저장소에 둔다. 교집합은 현재 커플에서 각자가 명시적으로 승인한 범위에만 적용한다. 승인된 날짜·지역은 상대가 알아낼 수 있음을 화면과 처리방침에 알린다.
