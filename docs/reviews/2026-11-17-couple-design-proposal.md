# 커플 앱 디자인 제안

## 현재 확인한 화면

앱은 지도·앨범·초대·설정을 Material 기본 컴포넌트로 구성한다. theme.dart는 기본 색상 seed만 정의한다. 사진과 퍼즐 데이터는 실제 기록이며 더미 여행을 넣지 않는다. 이 제안은 코드와 아이콘을 기준으로 작성했고 실기기 화면 평가는 별도로 필요하다.

## 추천 방향: 함께 모으는 작은 여행 수첩

‘귀여움’은 장식의 양보다 두 사람의 기록이 쌓이는 순간에 담는다. 지도와 사진을 주인공으로 두고, 개인정보·삭제·오류 화면은 명확하고 차분하게 유지한다.

| 요소 | 제안 | 지켜야 할 조건 |
| --- | --- | --- |
| 색상 | 따뜻한 크림색 표면, 코랄을 주 행동 색상, 살구색을 조각 채움에 사용 | 본문 대비 4.5:1, 다크 모드에서는 의미에 맞는 색상으로 전환 |
| 퍼즐 | 확인 완료 때 해당 조각이 짧게 제자리에 맞춰지는 반응 | 지도 형상·탭 좌표를 바꾸지 않고 모션 줄이기 설정 존중 |
| 문구 | 여행 확인 후 ‘우리의 조각이 하나 늘었어요’, 빈 앨범 ‘첫 여행을 여기 담아볼까요?’ | 실제 추가 조각 수와 상태에서만 표시; 오류·삭제에는 감성 표현 금지 |
| 초대 | 두 조각이 만나는 간결한 모티프와 연결 상태 | 사용자 사진이나 동의를 암시하는 가짜 상태 금지 |
| 앨범 | 사진을 넓게 보여주고 여행 날짜·지역을 수첩 캡션처럼 정리 | 사진 개수·제목·원본 보기 동작 유지 |
| 조작 | 둥근 모서리와 짧은 눌림 피드백, 명확한 설정·뒤로가기 | iOS 기본 탐색, 최소 44×44pt, 큰 글씨와 VoiceOver 지원 |

## 대안과 선택 근거

- 캐릭터 중심: 귀엽지만 지도·사진을 가리고 새 그림 자산 관리가 필요하다. 첫 개선으로는 비용이 크다.
- 진한 분홍색·하트 반복: 커플임은 즉시 드러나지만 여행 기록의 다양성이 줄고 장시간 보기 피곤하다.
- 따뜻한 수첩과 퍼즐 반응: 현재 앱 이름·기능과 자연스럽게 이어지고 기존 컴포넌트로 점진적으로 적용할 수 있다. 이 방향을 추천한다.

## 구현 전 확인할 것

이번 PR은 오류·권한·연결 흐름 수정만 구현하며 이 제안의 색상·모션·레이아웃 개편은 적용하지 않는다. 다음 디자인 작업에서는 iPhone 실제 화면으로 밝은/어두운 모드, 큰 글씨, 빈 앨범·긴 제목·사진 권한 거부를 한 번에 검토한다. 사용자 선택 이후 화면별 시안을 만들고 기존 애셋·컴포넌트를 최대한 재사용한다.
